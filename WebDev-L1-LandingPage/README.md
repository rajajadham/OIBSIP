# NovaSpace - Landing Page

## Oasis Infobyte Web Development Internship

### Level 1 - Task 1: Landing Page

This project was created as part of the Oasis Infobyte Web Development Internship.

## About the Project

NovaSpace is a modern and responsive landing page designed and developed by **Raja Jadham** using HTML5 and CSS3.

The website focuses on a clean, professional and modern digital design.

## Technologies Used

- HTML5
- CSS3
- Google Fonts

- Sticky navigation bar
- Hero section
- About section
- Services section
- Contact section
- Footer
- Smooth scrolling
- Responsive design
- Mobile-friendly layout
- Hover animations
- Modern typography
- Consistent color palette
