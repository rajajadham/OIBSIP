# RajaAuth — Login Authentication System

## Oasis Infobyte Web Development Internship

### Level 2 — Task 4

A client-side login authentication system built using HTML5, CSS3 and Vanilla JavaScript.

## Features

- User registration
- Email validation
- Password validation
- Duplicate email detection
- Login authentication
- Protected dashboard view
- Logout functionality
- SessionStorage for active login
- LocalStorage for registered demo users
- Responsive design
- Error handling

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- SessionStorage
