# TaskFlow — To-Do Web App

## Oasis Infobyte Web Development Internship

### Level 2 — Task 3

A responsive task management web application built using HTML5, CSS3 and Vanilla JavaScript.

## Features

- Add tasks
- Complete tasks
- Edit tasks
- Delete tasks
- Filter all tasks
- Filter pending tasks
- Filter completed tasks
- LocalStorage persistence
- Responsive design

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
