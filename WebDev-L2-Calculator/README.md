# RajaCalc — Calculator

## Oasis Infobyte Web Development Internship

### Level 2 — Task 1

A responsive calculator built using HTML5, CSS3 and Vanilla JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Clear button
- Backspace button
- Operator chaining
- Divide-by-zero handling
- Keyboard support
- Responsive design
- CSS Grid layout
- JavaScript event listeners
- No `eval()` function used

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
