# Temperature Converter

## Oasis Infobyte Web Development Internship

### Level 1 - Task 3: Temperature Converter

This project is a responsive temperature conversion web application created by **Raja Jadham** as part of the Oasis Infobyte Web Development Internship.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Numeric input validation
- Empty input validation
- Absolute-zero validation
- Conversion result display
- Clear button
- Responsive design
- Modern user interface

## Supported Units

### Celsius

- Minimum: -273.15°C

### Fahrenheit

- Minimum: -459.67°F

### Kelvin

- Minimum: 0 K
